A · Save timeout — right-aligned like Save prompt and Save to file.
B · Keyboard — Home clears focus when the app goes to the background, so returning never re-opens the keyboard over the tiles. The typed query is kept.
C · “+” in names — the name was URL-encoded with the form encoder (space → “+”) and navigation only decodes %20. Switching to proper URI encoding fixes it; “&”, “?”, “/” and “%” also survive.
D · Past meal — History gets a + Past meal button → date & time (starts at today, right now; you change the date/time; future refused) → the same picker → the usual quantity sheet → you land in that meal’s detail to add more. The meal is created closed, with your time as its start. If it falls inside the meal currently open, it is still a separate meal.
E · Languages — all UI text moves to strings.xml, with a French translation in values-fr. The app follows the phone language. On Android 13+ the user can also pick one for Glucarb only, from the Settings row (it opens Android’s per-app language page). French gets a decimal comma on the keypad and in figures. The default AI prompt is in French too, unless you have edited yours. CSV export keeps English headers and “.” decimals, so analysis scripts don’t break. The Play Store listing gets a French version too.
